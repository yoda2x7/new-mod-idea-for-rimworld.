# Universal Crafting Bench (RimWorld Mod)

This mod adds a universal crafting bench that can accept every recipe in the game, including DLC and modded content.

## What it does
- Adds a 2x1 bench (same footprint as a simple work bench).
- Costs **10 steel** to build.
- Automatically appears as a valid worktable for every RecipeDef, so you can add any bill to it.
- Sets recipe output to **5** for recipes that use `productCount`.
- Forces all recipe ingredient lists to **1 wood**.

## Install
1. Copy this folder into your RimWorld `Mods` directory.
2. Enable the mod in the in-game mod list.

## Notes
- Auto-translating non-English mod text to English is not supported by RimWorld's XML mod system.
  Translating other mods would require separate translation files for each mod.
